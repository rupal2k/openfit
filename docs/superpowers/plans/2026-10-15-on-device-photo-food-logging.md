# On-Device Photo Food Logging — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a user photograph a meal and get an editable list of foods, portions and calories. Recognition runs on a small vision-language model that the user downloads once from Hugging Face and then runs entirely on their own device, offline.

**Architecture:** OPENFIT copies the structure of fud-ai's Android on-device stack (catalogue → verified model manager → runtime → one analysis pipeline → review screen). Each layer is rebuilt for a web/Capacitor app:

- A pinned SmolVLM model (Apache-2.0) runs in a Web Worker through transformers.js, using WebGPU first and falling back to WASM. One code path serves the PWA, the desktop browser and the Android WebView.
- The model only **names foods and estimates grams**. Calories and macros come from a bundled USDA reference table.
- Nothing is logged until the user reviews it.

**Tech Stack:** React 19, Zustand 5, Vite 8, Vitest 4, `@huggingface/transformers` 4.3.1 (ONNX Runtime Web), Web Crypto, Cache Storage, Capacitor 7.

**Spec:** this document, sections "Background: fud-ai Android architecture" and "Design". (The request came from the user in chat on 2026-10-15; there is no separate spec file.)

## Global Constraints

- **Privacy:** photos never leave the device. No network request may carry image bytes. The only network traffic this feature creates is the one-time model download from `huggingface.co`.
- **Opt-in download:** the model downloads only after an explicit tap. Its exact size is shown first, and the download can be cancelled and the model deleted.
- **Pinned and verified:** every model file is pinned to a Hugging Face commit and checked against its published byte size **and** SHA-256 before first use. This is fud-ai's `downloadVerified` rule.
  - `HuggingFaceTB/SmolVLM-256M-Instruct` @ `7e3e67edbbed1bf9888184d9df282b700a323964`
  - `HuggingFaceTB/SmolVLM-500M-Instruct` @ `a7da5b986cb59b408707209984f360a5f4ad7e47`
- **One new runtime dependency:** `@huggingface/transformers` pinned exactly to `4.3.1`.
- **Nutrition source:** nutrition numbers come only from `frontend/src/data/generic-foods.json`. Calories generated by the model are never stored.
- **Entry shape unchanged:** `{ meal, g, food: { src, name, per100: { kcal, p, c, f } } }`, so totals, sync, backup and export need no change.
- **No regression:** with no model installed, the app behaves exactly as today. The APK does not grow by the model size, because the model is never bundled.
- **Strings:** all new UI strings go through `t()`. English fallback is acceptable.
- **Attribution:** `NOTICE.md` credits fud-ai (MIT) for the architecture and prompt patterns adapted here.

The model lifecycle lives in `services/ondevice/`:

| Class | Responsibility |
|---|---|
| `LocalModelCatalog` | Per-model descriptor: HF `resolve/<commit>/<file>` URL, `expectedBytes`, `sha256`, license, `minimumMemoryClassGb`, supported ABIs |
| `LocalModelEligibility` | RAM class = ceil(totalMem / GiB). Ineligible when RAM is below the minimum, the device is low-RAM, or the ABI is unsupported |
| `LocalModelManager` | `StateFlow` of `{ eligible, status: NotInstalled \| Downloading(bytes) \| Installed \| Failed(msg) }`. Install steps: (1) require free space ≥ size + max(256 MB, 10%); (2) stream into `.part` while hashing; (3) reject on Content-Length mismatch; (4) verify SHA-256; (5) rename into place and write a marker file holding the SHA-256. On startup a model counts as installed only if its size and marker both match. Supports cancel and delete |
| `LocalGemmaRuntime` | Gemma 4 E2B (`.litertlm`, 2.59 GB, ≥8 GB RAM) through LiteRT-LM |

### Pipeline

```
Photo sheet: camera / gallery  (+ optional note)
   │ prepImage(): ≤512 px JPEG (EXIF-oriented)                       lib/vision/image.js
   ▼
analyzeMeal({ image, note }, { generate })                           lib/vision/analyzer.js
   │ generate(image, buildPrompt(note))  ──▶ worker: SmolVLM (WebGPU→WASM)   worker.js / client.js
   │ parseDetections(text)  → [{ name, g }]                           parse.js
   │ matchFoods(name)       → top-3 { src:'generic', name, per100 }   match.js + generic-foods.json
   ▼
Review sheet: toggle · pick match · grams · meal · raw output        vision-sheets.jsx
   ▼
addEntry() per kept item  (existing store, sync, backup)             lib/nutrition.js
```

### Model lifecycle (state machine, mirrors `LocalModelInstallStatus`)

```
unknown ──refresh──▶ ineligible (reason)              — not enough RAM or storage
                 ├──▶ absent ──install──▶ downloading ──▶ verifying ──▶ ready ⇄ busy (analysing)
                 └──▶ ready              │  cancel ─▶ absent (purge)  │ bad hash ─▶ failed (purge)
                                         └─ GPU init error ─▶ failed, device := wasm (purge webgpu files)
ready ──delete──▶ absent (release worker, purge cache, clear marker)
ready ──90 s idle──▶ worker released (still "ready"; next analysis reloads from cache in seconds)
```

"Installed" on startup means every file for `(model, device)` is in Cache Storage **and** `localStorage['openfit.vision.verified.<model>.<device>'] === revision`. This is fud-ai's size-plus-marker rule. Hashing runs only once, after download.

### Error taxonomy (mirrors `AiError`)

| Kind | When | User message |
|---|---|---|
| `NOT_INSTALLED` | Analyse before download | Download the model first. |
| `LOW_MEMORY` | `deviceMemory` below the model minimum | This device doesn't have enough memory for this model. |
| `NO_STORAGE` | Free space < size + max(256 MB, 10%) | Not enough free storage for the model. |
| `DOWNLOAD` | Network or HTTP failure | Download failed — check your connection and try again. |
| `VERIFY` | Size or SHA-256 mismatch | The downloaded model failed verification and was removed. Try again. |
| `GPU_INIT` | WebGPU session creation fails | The GPU couldn't run the model, so OPENFIT switched to CPU mode. The CPU version needs its own download. |
| `IMAGE` | Photo cannot be decoded | That photo couldn't be read. Try a JPEG or PNG. |
| `CANCELLED` | User cancelled | (silent) |

### Platform notes

- **CapacitorHttp:** it patches `window.fetch`, which would push a 200 MB download through the native bridge. The worker's `fetch` is not patched, so every model request runs inside the worker. Hugging Face responds with `Access-Control-Allow-Origin: *`.
- **WebGPU:** Chrome desktop and Chrome Android (Android 12+) support it. Android WebView support depends on the version, so Task 1 measures it. WASM always works, only slower.
- **WASM threads** need cross-origin isolation, which the Capacitor WebView does not provide, so WASM runs single-threaded there. Task 1 measures how slow that is.
- **Camera:** `<input type="file" accept="image/*" capture="environment">` opens the camera in Chrome and in the Capacitor WebView. The APK already has the `CAMERA` permission.
- **Storage:** call `navigator.storage.persist()` before downloading so the browser won't evict the model under storage pressure.

import { AutoProcessor, AutoModelForVision2Seq, RawImage } from '@huggingface/transformers'
const REV = { 'HuggingFaceTB/SmolVLM-256M-Instruct': '7e3e67edbbed1bf9888184d9df282b700a323964',
              'HuggingFaceTB/SmolVLM-500M-Instruct': 'a7da5b986cb59b408707209984f360a5f4ad7e47' }
const PROMPT = 'List each food item in this photo with an estimated weight in grams. One item per line, format: <food> - <grams> g. No other text.'
const o = document.getElementById('o'), log = s => (o.textContent += '\n' + s)
const gpu = !!(navigator.gpu && (await navigator.gpu.requestAdapter().catch(() => null)))
o.textContent = `webgpu: ${gpu} · isolated: ${self.crossOriginIsolated} · cores: ${navigator.hardwareConcurrency} · deviceMemory: ${navigator.deviceMemory}`
document.getElementById('f').onchange = async e => {
  const repo = document.getElementById('m').value, revision = REV[repo]
  const device = gpu && !document.getElementById('cpu').checked ? 'webgpu' : 'wasm'
  const dtype = device === 'webgpu'
    ? { embed_tokens: 'fp16', vision_encoder: 'q4', decoder_model_merged: 'q4' }
    : { embed_tokens: 'int8', vision_encoder: 'int8', decoder_model_merged: 'q4' }
  let t0 = performance.now()
  const processor = await AutoProcessor.from_pretrained(repo, { revision })
  const model = await AutoModelForVision2Seq.from_pretrained(repo, { revision, dtype, device })
  log(`loaded ${repo} on ${device} in ${((performance.now() - t0) / 1000).toFixed(1)} s`)
  for (const file of e.target.files) {
    t0 = performance.now()
    const text = processor.apply_chat_template([{ role: 'user', content: [{ type: 'image' }, { type: 'text', text: PROMPT }] }], { add_generation_prompt: true })
    const inputs = await processor(text, [await RawImage.fromBlob(file)], { do_image_splitting: false })
    const out = await model.generate({ ...inputs, max_new_tokens: 160, do_sample: false, repetition_penalty: 1.1 })
    const [reply] = processor.batch_decode(out.slice(null, [inputs.input_ids.dims.at(-1), null]), { skip_special_tokens: true })
    log(`--- ${file.name} · ${((performance.now() - t0) / 1000).toFixed(1)} s\n${reply.trim()}`)
  }
  const keys = (await (await caches.open('transformers-cache')).keys()).map(r => r.url)
  log('cache keys:\n' + keys.filter(k => k.includes(repo)).join('\n'))
}
```

```js
// Turns a small VLM's free text into [{ name, g }]. Forgiving on purpose: 256M models drift
// between "Rice - 150 g", "1. Rice: about 150g" and the occasional fenced JSON array.
const LINE = /^\s*(?:(?:\d+[.)]|[-*•])\s+)?(.+?)\s*[-–—:,(]\s*(?:about|approx\.?|~)?\s*(\d+(?:[.,]\d+)?)\s*(kg|g|grams?|ml|oz)\b/i
const TO_G = { kg: 1000, oz: 28.35 }
const clampG = g => Math.min(1500, Math.max(5, Math.round(g)))

function fromJson(text) {
  const s = text.indexOf('['), e = text.lastIndexOf(']')
  if (s < 0 || e <= s) return null
  try {
    const arr = JSON.parse(text.slice(s, e + 1))
    return Array.isArray(arr) ? arr.map(x => ({ name: x?.name, g: +(x?.grams ?? x?.g) })) : null
  } catch { return null }
}

function fromLines(text) {
  const out = []
  for (const raw of text.split(/\n|;/)) {
    const m = raw.match(LINE)
    if (m) out.push({ name: m[1], g: parseFloat(m[2].replace(',', '.')) * (TO_G[m[3].toLowerCase()] || 1) })
  }
  return out
}

export function parseDetections(text) {
  const src = String(text || '')
  const rows = fromJson(src) || fromLines(src)
  const seen = new Set(), out = []
  for (const r of rows) {
    const name = String(r.name || '').replace(/["*_`]/g, '').trim().toLowerCase()
    if (!name || !(r.g > 0) || seen.has(name)) continue
    seen.add(name)
    out.push({ name, g: clampG(r.g) })
  }
  return out.slice(0, 8)
}

```js
// Maps a model's food name to reference nutrition. The model only names food; the numbers come
// from frontend/src/data/generic-foods.json (USDA FoodData Central, public domain).
import TABLE from '../../data/generic-foods.json'

const STOP = new Set(['and', 'with', 'the', 'of', 'a', 'some', 'piece', 'pieces', 'slice', 'slices', 'bowl', 'plate', 'cup', 'fresh', 'cooked', 'raw', 'small', 'large'])
const stem = w => w.endsWith('ies') ? w.slice(0, -3) + 'y'
  : w.endsWith('oes') ? w.slice(0, -2)
  : (w.endsWith('s') && !w.endsWith('ss') ? w.slice(0, -1) : w)
const words = s => String(s).toLowerCase().normalize('NFKD').replace(/[^a-z ]/g, ' ').split(/\s+/)
  .filter(w => w.length > 1 && !STOP.has(w)).map(stem)

const keyCache = new WeakMap()
const keysOf = f => {
  if (!keyCache.has(f)) keyCache.set(f, [words(f.name), ...(f.aka || []).map(words)])
  return keyCache.get(f)
}

function score(q, f) {
  let best = 0
  for (const k of keysOf(f)) {
    if (!k.length) continue
    const hit = q.filter(w => k.includes(w)).length
    best = Math.max(best, hit / q.length + 0.25 * (hit / k.length))   // query coverage + candidate coverage
  }
  return best
}

const snapshot = f => ({ src: 'generic', id: f.id, code: '', name: f.name, brand: '', serving: null, servingUnit: 'g', per100: { ...f.per100 } })

export function matchFoods(name, foods = TABLE, k = 3) {
  const q = words(name)
  if (!q.length) return []
  return foods.map(f => ({ f, s: score(q, f) }))
    .filter(x => x.s >= 0.5)
    .sort((a, b) => b.s - a.s || a.f.name.length - b.f.name.length)
    .slice(0, k)
    .map(x => snapshot(x.f))
}
```

// FoodData Central (public domain). Rows with a manual "kcal p c f" override skip the API.
// Usage: FDC_API_KEY=<free key: https://fdc.nal.usda.gov/api-key-signup> node scripts/build-generic-foods.mjs
import fs from 'fs'
import path from 'path'
import { fileURLToPath } from 'url'

const R = path.resolve(path.dirname(fileURLToPath(import.meta.url)), '..')
const KEY = process.env.FDC_API_KEY
if (!KEY) { console.error('Set FDC_API_KEY'); process.exit(1) }
const NUT = { kcal: [1008, 2047, 2048], p: [1003], c: [1005], f: [1004] }   // Energy (kcal / Atwater), protein, carbs, fat
const r1 = x => Math.round(x * 10) / 10

async function fdc(query) {
  const u = `https://api.nal.usda.gov/fdc/v1/foods/search?api_key=${KEY}&pageSize=1&dataType=Foundation,SR%20Legacy&query=${encodeURIComponent(query)}`
  const food = (await (await fetch(u)).json()).foods?.[0]
  if (!food) throw new Error('no FDC hit for ' + query)
  const val = ids => { for (const id of ids) { const n = food.foodNutrients.find(x => x.nutrientId === id); if (n) return n.value } return 0 }
  return { kcal: Math.round(val(NUT.kcal)), p: r1(val(NUT.p)), c: r1(val(NUT.c)), f: r1(val(NUT.f)), fdcName: food.description }
}

const out = []
for (const line of fs.readFileSync(path.join(R, 'scripts/generic-foods.txt'), 'utf8').split('\n')) {
  if (!line.trim() || line.startsWith('#')) continue
  const [id, query, aka, manual] = line.split('|').map(s => (s || '').trim())

  else { const h = await fdc(query); per100 = { kcal: h.kcal, p: h.p, c: h.c, f: h.f }; console.log(id, '←', h.fdcName) }
  const name = manual || !query ? aka.split(',')[0].trim().replace(/^\w/, c => c.toUpperCase()) : query.split(',').slice(0, 2).join(',')
  out.push({ id, name, aka: aka.split(',').map(s => s.trim()).filter(Boolean), per100 })
}

// cheap size check first, hash only when the size is right.
import { VisionError } from './errors.js'

export const toHex = buf => [...new Uint8Array(buf)].map(b => b.toString(16).padStart(2, '0')).join('')

export async function verifyBuffer(buf, spec, digest = (alg, data) => crypto.subtle.digest(alg, data)) {
  if (buf.byteLength !== spec.bytes) throw new VisionError('VERIFY', `size ${spec.path}`)

`frontend/src/lib/vision/worker.js`:
```js
// The on-device runtime — OPENFIT's LocalGemmaRuntime. One worker = one loaded model.
// Model files are fetched HERE: in the APK, CapacitorHttp patches window.fetch and would push a
// 200 MB download through the native bridge as base64; a worker's fetch is untouched, and
// Hugging Face allows CORS. Like fud-ai, a GPU init failure is reported so the client can fall
// back to CPU (WASM) instead of leaving the user with an unusable model.
import { AutoProcessor, AutoModelForVision2Seq, RawImage, env } from '@huggingface/transformers'
import { MODELS, deviceFiles, fileUrl } from './catalog.js'
import { MAX_NEW_TOKENS } from './prompt.js'
import { verifyBuffer } from './verify.js'

env.allowLocalModels = false
let cur = null

const fail = (kind, message) => Object.assign(new Error(message), { kind })

async function load(id, device, rid) {
  if (cur && cur.id === id && cur.device === device) return cur
  const m = MODELS[id]
  const progress_callback = p => {
    if (p.status === 'progress') postMessage({ rid, type: 'progress', file: p.file, loaded: p.loaded, total: p.total })
  }
  let processor
  try { processor = await AutoProcessor.from_pretrained(m.repo, { revision: m.revision, progress_callback }) }
  catch (e) { throw fail('DOWNLOAD', String(e?.message || e)) }
  let model
  try {
    model = await AutoModelForVision2Seq.from_pretrained(m.repo, { revision: m.revision, dtype: m.dtype[device], device, progress_callback })
  } catch (e) {
    const msg = String(e?.message || e)
    throw fail(device === 'webgpu' && !/fetch|network|HTTP|404|Failed to load/i.test(msg) ? 'GPU_INIT' : 'DOWNLOAD', msg)
  }
  cur = { id, device, processor, model }
  return cur
}

async function verify(id, device) {
  const m = MODELS[id]
  const c = await caches.open('transformers-cache')
  for (const f of deviceFiles(m, device)) {
    const r = await c.match(fileUrl(m, f.path))
    if (!r) throw fail('VERIFY', 'missing ' + f.path)
    try { await verifyBuffer(await r.arrayBuffer(), f) } catch (e) { throw fail('VERIFY', e.detail || e.message) }
  }
}

async function generate(id, device, image, prompt, rid) {
  const { processor, model } = await load(id, device, rid)
  let img
  try { img = await RawImage.fromBlob(image) } catch (e) { throw fail('IMAGE', String(e?.message || e)) }
  const chat = processor.apply_chat_template(
    [{ role: 'user', content: [{ type: 'image' }, { type: 'text', text: prompt }] }], { add_generation_prompt: true })
  const inputs = await processor(chat, [img], { do_image_splitting: false })
  const out = await model.generate({ ...inputs, max_new_tokens: MAX_NEW_TOKENS, do_sample: false, repetition_penalty: 1.1 })
  const [text] = processor.batch_decode(out.slice(null, [inputs.input_ids.dims.at(-1), null]), { skip_special_tokens: true })
  return text
}

self.onmessage = async ({ data }) => {
  const { rid, type, id, device } = data
  try {
    if (type === 'load') await load(id, device, rid)
    if (type === 'verify') await verify(id, device)
    const text = type === 'generate' ? await generate(id, device, data.image, data.prompt, rid) : undefined
    postMessage({ rid, type: 'ok', text })
  } catch (e) {
    postMessage({ rid, type: 'error', kind: e.kind || 'DOWNLOAD', message: String(e?.message || e) })
  }
}
```

`frontend/src/lib/vision/client.js`:
```js
// OPENFIT's LocalModelManager: lifecycle state for the UI, verified install, cancel, delete,
// and the worker RPC. transformers.js caches files in Cache Storage ('transformers-cache') under
// their Hugging Face resolve URL; we hash them once after download and then trust a marker
// (localStorage) — fud-ai's "size + marker" rule — so startup never re-hashes 200 MB.
import { create } from 'zustand'
import { MODELS, DEFAULT_MODEL, pickDevice, deviceFiles, downloadBytes, fileUrl, ineligibility } from './catalog.js'
import { VisionError } from './errors.js'

const CACHE = 'transformers-cache'
const K = { model: 'openfit.vision.model', device: 'openfit.vision.device' }
const IDLE_MS = 90_000
const ls = {
  get: k => { try { return localStorage.getItem(k) } catch { return null } },
  set: (k, v) => { try { v == null ? localStorage.removeItem(k) : localStorage.setItem(k, v) } catch { /* private mode */ } },
}
export const markerKey = (id, device) => `openfit.vision.verified.${id}.${device}`
export const sumProgress = files => Object.values(files).reduce(
  (a, f) => ({ loaded: a.loaded + (f.loaded || 0), total: a.total + (f.total || 0) }), { loaded: 0, total: 0 })

export const useVision = create(() => ({
  modelId: MODELS[ls.get(K.model)] ? ls.get(K.model) : DEFAULT_MODEL,
  device: null, state: 'unknown', reason: null, loaded: 0, total: 0, error: null,
}))
const set = p => useVision.setState(p)
const get = () => useVision.getState()

/* ---------- worker RPC (one engine at a time, like LocalGemmaRuntime's mutex) ---------- */
let worker = null, seq = 0, idle = null
const pending = new Map()
function release() {
  clearTimeout(idle)
  if (!worker) return
  worker.terminate(); worker = null
  for (const p of pending.values()) p.reject(new VisionError('CANCELLED'))
  pending.clear()
}
function call(msg, onProgress) {
  clearTimeout(idle)
  if (!worker) {
    worker = new Worker(new URL('./worker.js', import.meta.url), { type: 'module' })
    worker.onmessage = ({ data }) => {
      const p = pending.get(data.rid)
      if (!p) return
      if (data.type === 'progress') { p.onProgress?.(data); return }
      pending.delete(data.rid)
      data.type === 'ok' ? p.resolve(data) : p.reject(new VisionError(data.kind, data.message))
    }
  }
  const rid = ++seq
  return new Promise((resolve, reject) => {
    pending.set(rid, { resolve, reject, onProgress })
    worker.postMessage({ ...msg, rid })
  })
}
const scheduleRelease = () => { clearTimeout(idle); idle = setTimeout(release, IDLE_MS) }

/* ---------- detection ---------- */
async function detectDevice() {
  const saved = ls.get(K.device)
  if (saved === 'wasm' || saved === 'webgpu') return saved
  try { return pickDevice(!!(navigator.gpu && (await navigator.gpu.requestAdapter()))) } catch { return 'wasm' }
}
async function cachedAll(m, device) {
  if (!('caches' in self)) return false
  const c = await caches.open(CACHE)
  return (await Promise.all(deviceFiles(m, device).map(f => c.match(fileUrl(m, f.path))))).every(Boolean)
}
async function purge(m) {
  if (!('caches' in self)) return
  const c = await caches.open(CACHE)
  for (const req of await c.keys()) if (req.url.includes(`/${m.repo}/`)) await c.delete(req)
}

export async function refreshVision() {
  const device = await detectDevice()
  const m = MODELS[get().modelId]
  const installed = ls.get(markerKey(m.id, device)) === m.revision && await cachedAll(m, device)
  if (installed) { set({ device, state: 'ready', reason: null, error: null }); return }
  const est = await navigator.storage?.estimate?.().catch(() => null)
  const reason = ineligibility(m, { deviceMemoryGb: navigator.deviceMemory, freeBytes: est?.quota ? est.quota - est.usage : null })
  set({ device, state: reason ? 'ineligible' : 'absent', reason, total: downloadBytes(m, device), error: null })
}

export async function setVisionModel(id) {
  if (!MODELS[id] || id === get().modelId) return
  release()
  ls.set(K.model, id)
  set({ modelId: id, state: 'unknown' })
  await refreshVision()
}

/* ---------- install / cancel / remove ---------- */
export async function installModel() {
  const { modelId, device } = get()
  const m = MODELS[modelId]
  await navigator.storage?.persist?.().catch(() => false)
  const files = {}
  set({ state: 'downloading', loaded: 0, total: downloadBytes(m, device), error: null })
  try {
    await call({ type: 'load', id: modelId, device }, p => {
      files[p.file] = p
      set({ loaded: Math.min(sumProgress(files).loaded, get().total) })
    })
    set({ state: 'verifying' })
    await call({ type: 'verify', id: modelId, device })
    ls.set(markerKey(modelId, device), m.revision)
    set({ state: 'ready' })
    scheduleRelease()
  } catch (e) {
    const err = e instanceof VisionError ? e : new VisionError('DOWNLOAD', String(e?.message || e))
    release()
    if (err.kind === 'CANCELLED') { await purge(m); set({ state: 'absent', loaded: 0 }); return }
    if (err.kind === 'GPU_INIT') { ls.set(K.device, 'wasm'); await purge(m); set({ device: 'wasm', total: downloadBytes(m, 'wasm') }) }
    if (err.kind === 'VERIFY') await purge(m)
    set({ state: 'failed', error: err.message })
    throw err
  }
}

export const cancelInstall = () => release()

export async function removeModel() {
  release()
  const m = MODELS[get().modelId]
  await purge(m)
  ls.set(markerKey(m.id, 'webgpu'), null)
  ls.set(markerKey(m.id, 'wasm'), null)
  set({ state: 'absent', loaded: 0, error: null })
}

/* ---------- inference ---------- */
export async function generate(image, prompt) {
  const { modelId, device, state } = get()
  if (state !== 'ready') throw new VisionError('NOT_INSTALLED')
  set({ state: 'busy', error: null })
  try {
    const { text } = await call({ type: 'generate', id: modelId, device, image, prompt })
    set({ state: 'ready' })
    scheduleRelease()
    return text || ''
  } catch (e) {
    set({ state: 'ready' })
    if (e.kind === 'GPU_INIT') { ls.set(K.device, 'wasm'); ls.set(markerKey(modelId, device), null); await refreshVision() }
    throw e
  }
}

export const cancelGenerate = () => release()
```

```jsx
// On-device photo logging UI: model management (Settings), capture, and review.
// Mirrors fud-ai's flow: capture → analyse (local model) → review/edit → save.
import { useEffect, useRef, useState } from 'react'
import { useStore } from './store/useStore.js'
import { useUI } from './store/useUI.js'
import { t } from './lib/i18n.js'
import { fmtNum } from './lib/format.js'
import { addEntry, entryTotals, MEALS } from './lib/nutrition.js'
import { MODELS, downloadBytes } from './lib/vision/catalog.js'
import { MESSAGES } from './lib/vision/errors.js'
import { prepImage } from './lib/vision/image.js'
import { analyzeMeal } from './lib/vision/analyzer.js'
import { useVision, refreshVision, setVisionModel, installModel, cancelInstall, removeModel, generate, cancelGenerate } from './lib/vision/client.js'
import { MEAL_LABEL } from './nutrition-sheets.jsx'
import { Button, Segmented, Stepper, Switch, Row, Section, TextField } from './components/ui.jsx'

const ui = () => useUI.getState()
const toast = m => ui().toast(m)
const mb = b => Math.round((b || 0) / 1e6)
const quiet = e => { if (e?.kind !== 'CANCELLED') toast(t(e?.message || 'Something went wrong')) }

function Progress({ loaded, total }) {
  const pct = total ? Math.min(100, (loaded / total) * 100) : 0
  return <div role="progressbar" aria-valuenow={Math.round(pct)} aria-valuemin={0} aria-valuemax={100}
    style={{ height: 6, borderRadius: 3, background: 'var(--surface-2)', overflow: 'hidden', margin: '8px 0' }}>
    <div style={{ width: pct + '%', height: '100%', background: 'linear-gradient(90deg,var(--acc),var(--acc-2))', transition: 'width .3s' }} />
  </div>
}

function statusLine(v) {
  const m = MODELS[v.modelId]
  switch (v.state) {
    case 'ready': case 'busy': return t('Installed · runs on {0}', v.device === 'webgpu' ? t('GPU') : t('CPU'))
    case 'downloading': return t('Downloading {0} / {1} MB', mb(v.loaded), mb(v.total))
    case 'verifying': return t('Verifying download…')
    case 'ineligible': return t(MESSAGES[v.reason])
    case 'failed': return v.error ? t(v.error) : t('Download failed')
    case 'absent': return t('{0} MB download · {1}', mb(downloadBytes(m, v.device || 'wasm')), m.license)
    default: return t('Checking…')
  }
}

function ModelActions({ v }) {
  if (v.state === 'ready') return <Button size="sm" variant="danger" onClick={() => removeModel().then(() => toast(t('Model removed')))}>{t('Delete')}</Button>
  if (v.state === 'downloading' || v.state === 'verifying') return <Button size="sm" variant="ghost" onClick={cancelInstall}>{t('Cancel')}</Button>
  if (v.state === 'absent' || v.state === 'failed') return <Button size="sm" variant="tinted"
    onClick={() => installModel().then(() => useVision.getState().state === 'ready' && toast(t('Model ready — works offline'))).catch(quiet)}>{t('Download')}</Button>
  return null
}

/* ---------------------------------------------------------------- settings */
export function VisionSettings() {
  const v = useVision()
  useEffect(() => { refreshVision() }, [])
  const m = MODELS[v.modelId]
  const locked = v.state === 'downloading' || v.state === 'verifying' || v.state === 'busy'
  return <Section title={t('On-device food recognition')}
    footer={t('Photos are analysed on this device and never uploaded. The model is downloaded once from Hugging Face ({0}) and then works offline.', m.license)}>
    <Row title={t('Model')}>
      <Segmented className="seg-inline" value={v.modelId} onChange={id => !locked && setVisionModel(id)}
        options={Object.values(MODELS).map(x => ({ value: x.id, label: t(x.label.split(' · ')[0]) }))} />
    </Row>
    <Row icon="camera" iconTint="var(--acc)" title={m.label} subtitle={statusLine(v)}><ModelActions v={v} /></Row>
    {(v.state === 'downloading' || v.state === 'verifying') && <Progress loaded={v.state === 'verifying' ? v.total : v.loaded} total={v.total} />}
  </Section>
}

/* ------------------------------------------------------------ photo sheet */
export const photoSheet = (iso, meal) => ui().openSheet(close => <Photo iso={iso} meal={meal} close={close} />)

function Photo({ iso, meal, close }) {
  const v = useVision()
  const camRef = useRef(null), libRef = useRef(null)
  const [img, setImg] = useState(null)            // { blob, url }
  const [note, setNote] = useState('')
  const [secs, setSecs] = useState(0)
  useEffect(() => { refreshVision() }, [])
  useEffect(() => () => { if (img) URL.revokeObjectURL(img.url) }, [img])
  useEffect(() => () => cancelGenerate(), [])
  useEffect(() => {
    if (v.state !== 'busy') return
    setSecs(0)
    const id = setInterval(() => setSecs(s => s + 1), 1000)
    return () => clearInterval(id)
  }, [v.state])

  const pickFile = async e => {
    const f = e.target.files?.[0]
    e.target.value = ''
    if (!f) return
    try { const blob = await prepImage(f); setImg({ blob, url: URL.createObjectURL(blob) }) } catch (err) { quiet(err) }
  }
  const run = async () => {
    try {
      const r = await analyzeMeal({ image: img.blob, note }, { generate })
      close()
      reviewSheet(iso, meal, r.items, r.text)
    } catch (e) { quiet(e) }
  }

  if (v.state !== 'ready' && v.state !== 'busy') return <>
    <h3>{t('Log food from a photo')}</h3>
    <div className="small muted" style={{ marginBottom: 12 }}>
      {t('Recognition runs entirely on your device — photos are never uploaded. Download the model once to start.')}
    </div>
    <Row icon="camera" iconTint="var(--acc)" title={MODELS[v.modelId].label} subtitle={statusLine(v)}><ModelActions v={v} /></Row>
    {(v.state === 'downloading' || v.state === 'verifying') && <Progress loaded={v.state === 'verifying' ? v.total : v.loaded} total={v.total} />}
  </>

  return <>
    <h3>{t('Log food from a photo')}</h3>
    <input ref={camRef} type="file" accept="image/*" capture="environment" hidden onChange={pickFile} />
    <input ref={libRef} type="file" accept="image/*" hidden onChange={pickFile} />
    {img
      ? <img src={img.url} alt={t('Meal photo')} style={{ width: '100%', borderRadius: 12, display: 'block', marginBottom: 10 }} />
      : <div className="row" style={{ gap: 8, marginBottom: 10 }}>
          <Button variant="primary" icon="camera" onClick={() => camRef.current.click()}>{t('Take photo')}</Button>
          <Button variant="tinted" icon="upload" onClick={() => libRef.current.click()}>{t('Choose photo')}</Button>
        </div>}
    {img && v.state !== 'busy' && <>
      <TextField value={note} onChange={e => setNote(e.target.value)} placeholder={t('Optional note, e.g. “half portion of rice”')} />
      <div className="row" style={{ gap: 8, marginTop: 10 }}>
        <Button variant="ghost" onClick={() => setImg(null)}>{t('Retake')}</Button>
        <Button variant="primary" icon="sparkles" onClick={run}>{t('Analyse')}</Button>
      </div>
    </>}
    {v.state === 'busy' && <>
      <div className="small muted" style={{ margin: '8px 0' }}>{t('Analysing on your device… {0} s', secs)}</div>
      <Button variant="ghost" onClick={cancelGenerate}>{t('Cancel')}</Button>
    </>}
  </>
}

/* ----------------------------------------------------------- review sheet */
const reviewSheet = (iso, meal, items, raw) => ui().openSheet(close => <Review iso={iso} meal0={meal} items0={items} raw={raw} close={close} />)

function Review({ iso, meal0, items0, raw, close }) {
  const [items, setItems] = useState(items0)
  const [meal, setMeal] = useState(meal0)
  const [showRaw, setShowRaw] = useState(false)
  const patch = (i, p) => setItems(xs => xs.map((x, j) => (j === i ? { ...x, ...p } : x)))
  const kept = items.filter(x => x.on && x.options[x.pick])
  const total = kept.reduce((s, x) => s + entryTotals({ g: x.g, food: x.options[x.pick] }).kcal, 0)
  const save = () => {
    useStore.getState().update(s => { for (const x of kept) addEntry(s, iso, { meal, g: x.g, food: x.options[x.pick] }) })
    close()
    toast(t('Added {0} items to {1}', kept.length, t(MEAL_LABEL[meal])))
  }
  const rawBlock = raw && <>
    <Button size="sm" variant="ghost" onClick={() => setShowRaw(s => !s)}>{showRaw ? t('Hide model output') : t('Show model output')}</Button>
    {showRaw && <pre className="small dim" style={{ whiteSpace: 'pre-wrap', margin: '6px 0 10px' }}>{raw}</pre>}
  </>

  if (!items.length) return <>
    <h3>{t('Nothing recognised')}</h3>
    <div className="small muted" style={{ marginBottom: 12 }}>{t('Try a closer, well-lit photo of one plate, or add the food by search.')}</div>
    {rawBlock}
    <Button variant="tinted" onClick={close}>{t('Close')}</Button>
  </>

  return <>
    <h3>{t('Check what was found')}</h3>
    <div className="small muted" style={{ marginBottom: 10 }}>{t('Estimates from a small on-device model — adjust before adding.')}</div>
    {items.map((x, i) => {
      const food = x.options[x.pick]
      return <div key={i} className="card" style={{ marginBottom: 8 }}>
        <div className="row between">
          <b className="capitalize">{x.name}</b>
          <Switch checked={x.on} disabled={!food} onChange={on => patch(i, { on })} aria-label={t('Include {0}', x.name)} />
        </div>
        {food ? <>
          {x.options.length > 1 && <div style={{ margin: '8px 0' }}>
            <Segmented value={x.pick} onChange={pick => patch(i, { pick })} options={x.options.map((o, k) => ({ value: k, label: o.name.split(',')[0] }))} />
          </div>}
          <Stepper label={t('Amount')} unit="g" value={x.g} step={10} decimal={false} onChange={g => patch(i, { g })} />
          <div className="small muted">{food.name} · {fmtNum(entryTotals({ g: x.g, food }).kcal)} kcal</div>
        </> : <div className="small muted">{t('No reference match — add it with search instead.')}</div>}
      </div>
    })}
    <div style={{ margin: '12px 0' }}><Segmented value={meal} onChange={setMeal} options={MEALS.map(m => ({ value: m, label: t(MEAL_LABEL[m]) }))} /></div>
    {rawBlock}
    <Button variant="primary" disabled={!kept.length} onClick={save}>{t('Add {0} items · {1} kcal', kept.length, fmtNum(total))}</Button>
  </>
}
```
