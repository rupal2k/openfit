# OPENFIT Labs v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Import blood test PDFs on the device, review them, chart each marker over time, and show seven published clinical scores plus PhenoAge, with no network use and no AI model.

**Architecture:** A small `lib/labs/` package (catalogue, units, text parser, PDF text, scores) feeds a new `Labs` view. Reports live in the existing state under `S.labs`, so local storage, self-hosted sync, the Android file mirror and JSON backups carry them unchanged.

**Tech Stack:** React 19, Zustand, Vitest, `pdfjs-dist` (Apache-2.0, new and the only new dependency).

**Spec:** `docs/PRD-openfit-labs.md`

## Global Constraints

- No network request during import: pdf.js and its worker are bundled, never loaded from a CDN.
- Canonical units are SI, following getbased's catalogue; conversions use getbased's factors (credited in NOTICE.md).
- A value is stored only after the person confirms it on the review screen.
- Each result keeps the lab's printed range. No unsourced "optimal" ranges.
- Every score names its formula and source, and appears only when all its inputs exist in one report.
- Scores are wellness information; the Labs view says it is not medical advice.
- UI strings go through `t()`; other languages fall back to English until translated.
- Status is never colour alone: a range flag always has a text label.

## Review Focus

1. A report in mg/dL and a later one in mmol/L chart on one line in one unit. Test: `units.test.js` round-trips both.
2. A line with a "<" or ">" value, or an "H"/"L" flag, still parses its number and range. Test: `parse.test.js`.
3. A non-numeric row ("Negative") or an unknown marker is listed as unmatched, not dropped or mis-mapped. Test: `parse.test.js`.
4. Two devices that import the same report merge to one copy, and reports from both survive. Test: `sync.test.js`.
5. A score whose input is missing or zero (CRP 0 for PhenoAge) shows nothing instead of NaN. Test: `scores.test.js`.

### Task 3: Scores
**Files:** Create `frontend/src/lib/labs/scores.js`, test `scores.test.js`
**Produces:** `labScores(values: {[key]: canonical number}, { age, sex }) -> [{ id, name, value, unit, band, note, formula, source }]`
- HOMA-IR = insulin µIU/mL × glucose mmol/L ÷ 22.5 (Matthews 1985). TG/HDL in mg/dL. ApoB/ApoA1. FIB-4 = age × AST ÷ (platelets × √ALT) (Sterling 2006; cut-offs 1.30 / 2.67, Shah 2009). Non-HDL = TC − HDL. Homocysteine and Omega-3 Index read directly. PhenoAge (Levine 2018).
- [ ] Tests against hand-calculated values; missing input → score absent; CRP ≤ 0 → no PhenoAge.
- [ ] Commit.
