# Test Plan — OPENFIT Web + Android
**Date:** 2026-10-27

---

## Web App Test (Browser / PWA)

### Prerequisites
```bash
git clone https://github.com/rupal2k/openfit.git
cd openfit && cp .env.example .env
docker compose up -d --build
# open http://localhost:8080
```

### Test cases

| # | Area | Steps | Expected |
|---|---|---|---|
| W1 | Register | Open localhost:8080 → Create profile → enter name → tap Create passkey → follow OS prompt | Profile created, lands on Home |
| W2 | Guest mode | Open fresh incognito window → Start as guest | Home loads with empty data |
| W3 | Start workout | Home → Start workout → pick a routine → start | Workout timer starts, first exercise shown |
| W4 | Log a set | In workout, enter weight + reps → tap check | Set marked done, rest timer starts |
| W5 | Finish workout | Complete all sets → Finish workout | Summary shown, workout saved to History |
| W6 | Stats heatmap | Nav to Stats | 12-month heatmap renders, today cell is highlighted |
| W7 | Exercise Library | Nav to Library → search "bench" | Filtered results, tap exercise → demo animation plays |
| W8 | Nutrition log | Nav to Nutrition → Add food → search "chicken" | Food results appear, add one, macro tiles update |
| W9 | Settings theme | Settings → Accent color → tap a swatch | Theme color changes across the app |
| W10 | Backup + restore | Settings → Export backup → re-import the file | All data restored exactly |
| W11 | PWA install | Chrome: ⋮ menu → Add to Home Screen | App installs, opens full-screen (no browser UI) |
| W12 | Offline | Start workout, turn off WiFi, complete it | Workout saved locally; syncs when back online |

### Keyboard / accessibility spot-checks

| # | Steps | Expected |
|---|---|---|
| A1 | Tab through Login screen | Name field focused, then passkey button, then Sign in — no focus traps |
| A2 | Tab through Library search | Search field reachable, `aria-label="Search exercises"` |
| A3 | Tab through workout routine picker | Each routine row focusable and activatable with Enter/Space |

## Android App Test (Sideload APK)

### Prerequisites
1. Download APK: `https://github.com/rupal2k/openfit/releases/latest/download/OPENFIT-android.apk`
2. On device: Settings → Apps → Special app access → Install unknown apps → enable for your browser/Files app
3. Open the downloaded APK and install

### Test cases

| # | Area | Steps | Expected |
|---|---|---|---|
| A1 | Launch | Open OPENFIT from launcher | Splash → Home loads (no browser address bar) |
| A2 | Guest profile | Tap "Start as guest" | Home with empty state, no server required |
| A3 | Log workout | Start workout → pick routine → log sets → finish | Workout saved to on-device storage |
| A4 | Barcode scanner | Nutrition → Scan barcode → point at a food product | Barcode scanned, food pre-filled |
| A5 | Camera food log | Nutrition → camera icon → take photo of a dish | On-device AI identifies dish, nutrition pre-filled |
| A6 | Offline | Enable airplane mode → log a full workout | Works offline; no error shown |
| A7 | Rotation | Rotate device mid-workout | Layout adapts; no data loss |
| A8 | Back navigation | Use Android back button in each view | Navigates correctly, no crash |
| A9 | Wake lock | Start workout → lock screen mid-set | Screen wakes/stays on (if Keep screen on is enabled) |
| A10 | Export backup | Settings → Export backup → share/save JSON | File exported successfully |

## Automated regression (run before any deployment)

```bash
# API integration tests
cd api && node --test api.test.js server.test.js

# Frontend unit tests  
cd frontend && npm run test
```

Both suites must pass (0 failures) before merging.

---

## Known limitations

- Playwright MCP not currently connected — browser automation tests are manual for now.
- Android device tests require a physical device or emulator (ADB).
- Passkey registration only works over HTTPS (or localhost) — test on device via LAN requires a self-signed cert or Cloudflare Tunnel.
